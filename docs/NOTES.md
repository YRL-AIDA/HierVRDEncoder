# Заметки

## Multi-prov: блоки на стыке страниц

**Наблюдение.** `item.prov` (provenance: `page_no` + `bbox` + `charspan`) это список. В сабсете у 257 из 12 647 блоков (2.0%) он длиннее одного, у 230 текст разбит между страницами, встречаются в 22 документах из 84. Это абзацы, переходящие через разрыв страницы. Сейчас подобные блоки считаются несвязанными, а одна страница забирает текст из другой.

**Решение.** Выдавать по одному блоку на `(item, prov)`: резать текст по `prov.charspan` и добавить колонку `item_ref` (`self_ref` Docling) — общую для всех частей одного элемента.

- Информация для разделов не теряется: page-уровень получает правильные страницы, а section/document склеиваются по `item_ref` или по соседству в `reading_order`; границы раздела задают `heading` и порядок чтения.
- Главное не забыть `item_ref`, чтобы не считать блоки на разных страницах независимыми.

## Ячейки таблиц: отрицательный bbox

**Наблюдение.** В кэше 507 таблицеподобных объектов (478 с меткой `table` + 29 `document_index` — оглавления) и 50 905 ячеек; из них 2 без `bbox`, 195 объединённых (`row_span`/`col_span > 1`). Блоки в манифесте — это уровень таблицы целиком (markdown-текст + bbox), геометрия ячеек не сохраняется.

У некоторых ячеек сырой `bbox.l` отрицательный (до −223 pt): модель табличной структуры экстраполировала ячейку за край страницы, а `docling-core` при загрузке JSON сжимает его в 0 (`_clamp_bbox_to_page`).

**Следствия.**

- assert «bbox в границах» проверяет только блоки, но не ячейки.
- если понадобятся признаки по ячейкам, брать сырые значения из свежего парса, а не из кэша JSON (там только информация по самим таблицам).

## OCR выключен

**Наблюдение.** Пока работаю только с PDF с текстовым слоем OCR не использую, иначе ошибки OCR смешались бы с ошибками модели, и их не отличить.

**Решение.** `do_ocr=False` в `build_manifest.py`.

**Статус.** Пересмотреть, когда начну работать с документами без текстового слоя.

## Формулы

**Наблюдение**. `do_formula_enrichment=True` затратная на CPU.

**Следствие.** Формулы пустые.

**Статус.** На данный момент выключена.
